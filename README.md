# PHIL-MY-HEART — 필리핀 단기선교 사진관

> 아이들과 함께 사진을 찍고, **요한복음 3:16과 함께 한 장에 담아** 그 자리에서 인화해 주는 키오스크

태블릿으로 사진을 찍으면 말씀과 합성해 감열 프린터로 즉석 출력합니다.
**서버도, 계정도, API 키도, 통신비도 필요 없습니다.** 사진은 전송되지 않고 그 기기 안에만 남습니다.
현지 인터넷이 없어도 한 번 열어 둔 화면이면 계속 쓸 수 있습니다.

## 인화되는 말씀

**John 3:16 (NIV)** 한 구절 고정입니다.

> For God so loved the world that he gave his one and only Son,
> that whoever believes in him shall not perish but have eternal life.

NIV는 저작권이 있는 번역입니다. 게시물·인쇄물에 본문을 실을 때는 **인용 끝에 `(NIV)` 표기**가 있어야 해서,
출처 문자열 자체를 `"John 3:16 (NIV)"` 로 두어 카드에 항상 함께 찍히도록 했습니다.

## 어떤 기기에서 인쇄되나요

사진 찍기·카드 만들기·저장·공유는 **어느 기기 어느 브라우저에서나** 됩니다.
갈리는 건 **블루투스 인쇄** 하나뿐입니다.

| 기기 | 브라우저 | 인쇄 |
|---|---|---|
| 안드로이드 태블릿·폰 | 크롬 | ✅ **현장 운영 권장** |
| 맥북 · 윈도우 PC | 크롬 / 엣지 | ✅ |
| **아이패드 · 아이폰** | **Bluefy** (무료, 앱스토어) | ✅ |
| 아이패드 · 아이폰 | 사파리 · 크롬 · 엣지 | ❌ |
| 맥북 | 사파리 | ❌ |

### 아이패드·아이폰에서 인쇄하기

애플은 사파리에 블루투스(Web Bluetooth)를 허용하지 않고, **앱스토어 규정상 아이폰용 크롬·엣지도
사파리와 같은 엔진을 쓰도록 강제**되어 있어 브라우저를 바꿔도 소용이 없습니다.
이 앱의 한계가 아니라 애플의 정책입니다.

해결책은 **자체 블루투스 기능을 갖춘 브라우저 앱**으로 여는 것입니다:

1. 아이패드에서 위 주소를 열면 상단에 안내 배너가 뜹니다 → **[📋 Copy address]**
2. **[Get Bluefy]** → 앱스토어에서 무료 설치 ([Bluefy – Web BLE Browser](https://apps.apple.com/app/id1492822055))
3. Bluefy를 열고 주소창에 붙여넣기 → **그 뒤로는 안드로이드와 똑같이 인쇄됩니다**
4. Bluefy에서도 홈 화면에 추가해 키오스크로 쓸 수 있습니다

> 배너는 블루투스를 못 쓰는 애플 기기에서만 뜹니다. Bluefy로 열면 저절로 사라집니다.
> (브라우저 이름이 아니라 **블루투스가 실제로 되는지**를 보고 판단하기 때문입니다.)

## 출국 전 준비 (5분)

1. 태블릿/폰에서 위 주소를 엽니다 (안드로이드는 **크롬**, 아이패드는 **Bluefy**)
2. 메뉴 → **홈 화면에 추가** → 전체화면 키오스크 완성
3. ⚙ Settings에서 **Card title · Footer line**을 확인합니다 (설정은 그 기기에만 저장됩니다)
   - 기본값: `PHIL-MY-HEART` / `Philippines Mission · Jesus loves you`
4. 프린터 전원을 켜고 **[🖨 Print]** → 블루투스 기기 선택창에서 `GB`/`GT`/`MX`/`YT`/`SC`로 시작하는 이름을 고릅니다. 한 번 연결하면 계속 유지됩니다
5. **출국 전에 한 번은 실제로 인쇄해 보세요.** 현지에서 처음 눌러 보면 늦습니다

### 준비물 (총 2~3만원대)

| 품목 | 비고 |
|---|---|
| 감열 프린터 | "고양이 프린터"로 검색 — GB/GT/YT/MX/SC 계열 (SC05 실사용 검증) |
| 감열지 롤 | **57mm 폭**. 아이들이 오래 간직할 카드라 고보존(long-life) 감열지 권장 |
| 태블릿/폰 | 안드로이드는 크롬, 아이패드는 Bluefy (위 표 참고) |
| 보조배터리 | 현지 전원 사정이 나쁠 수 있습니다. 프린터·태블릿 둘 다 |
| 감열지 여분 | 한 롤에 몇 장 나오는지 출국 전에 세어 보고 넉넉히 |

> **구매 전 확인**: 겉모양이 같아도 칩셋이 다릅니다. 브랜드 제품(PeriPage/Paperang)은 독자 프로토콜로
> 비호환이고, 영수증형(PT-210 등)은 블루투스 클래식이라 연결 자체가 안 됩니다.
> 판매자에게 **"블루투스 페어링 시 뜨는 기기 이름"**을 물어보세요.

## 현장 운영

**관리할 것은 두 가지뿐입니다 — 충전, 그리고 감열지 롤 교체.**

1. 프린터·태블릿 **충전**
2. 감열지 롤 교체 시 **인쇄면 방향 주의** (거꾸로 넣으면 연결은 되는데 백지가 나옵니다)
3. 인쇄가 갑자기 안 되면 → 프린터 전원 버튼으로 **절전 해제** 후 다시 [🖨 Print]
4. 촬영 원칙 → **찍히는 아이가 밝은 쪽(창문·조명)을 바라보게**. 열대 지역 실내는 역광이 심합니다
5. 촬영을 부끄러워하는 아이에게는 **[✍️ Make a card without a photo]** — 이름과 말씀만 인쇄됩니다
6. 이름은 아이가 직접 적게 해도 좋습니다. 적힌 그대로 인쇄됩니다

### ⚙ Settings에서 바꿀 수 있는 것
- **Card title** (카드 상단) · **Footer line** (카드 하단)
- **Print darkness** — 흐리면 올리고, 사진이 뭉개지면 내립니다

## 로고 넣기

지금은 로고 파일이 없어서 `drawHeartMark()` 가 **캔버스에 하트를 직접 그립니다.**
외부 파일이나 폰트에 의존하지 않아 어느 기기에서든 똑같이 나옵니다.

로고 PNG가 준비되면 3단계로 교체합니다:

1. 로고 이미지를 준비합니다 (**단색·투명 배경**이 감열 인쇄에 가장 잘 나옵니다)
2. 그 이미지의 알파 채널을 그레이스케일 PNG(마스크)로 만들어 base64로 인코딩
3. `index.html`의 `const LOGO_SRC = '';` 에 `'data:image/png;base64,…'` 를 넣습니다
   → 값이 비어 있지 않으면 하트 대신 그 로고가 그려집니다

색을 바꾸려면 같은 파일 `logoCanvas()` 안 `p[i]=11; p[i+1]=92; p[i+2]=168;` (RGB) 를 수정합니다.

> **왜 파일 경로가 아니라 문자열로 넣나요?**
> 인쇄용 흑백 변환은 캔버스에서 픽셀을 직접 읽습니다(`getImageData`). 외부 이미지 파일을
> `file://`이나 다른 출처에서 불러오면 캔버스가 오염(tainted)되어 이 읽기가 보안 예외로 실패합니다.
> data URI는 같은 출처로 취급되어 어디서 열어도 안전합니다.

로고가 뭉개지거나 너무 옅으면 `logoCanvas()`의 임계값(`m > 110`)이나 `LOGO_W`(기본 96px)를 조정하세요.

**홈 화면 아이콘**: 현재 파비콘은 인라인 SVG 하트입니다. iOS 홈 화면 아이콘까지 챙기려면
180×180 PNG를 `assets/logo.png` 로 넣고 `<head>`에 아래 줄을 되살리면 됩니다.

```html
<link rel="apple-touch-icon" href="assets/logo.png">
```

## 문구·말씀 바꾸기

- **말씀**: `index.html`의 `const VERSES = [ ["본문", "출처"], … ]`
- 기본 카드 제목·하단 문구: 같은 파일 `const cfg` 의 기본값 (기기별 설정이 우선합니다)

### 지금은 한 구절 고정입니다

여러 말씀에서 무작위로 뽑고 싶다면 — `index.html`에서 3단계:

1. `VERSES` 배열에 `["본문", "출처"]` 를 더 넣습니다
2. `function pickVerse(){ return 0; }` → `return Math.floor(Math.random()*VERSES.length);`
3. `📖 Another verse` 버튼 관련 주석 3곳(버튼 HTML · 표시 제어 · 클릭 핸들러)을 풉니다

> 말씀을 뽑는 시점이 여러 곳(첫 화면·촬영 후·사진 업로드 후·사진 없이 카드)이라
> `pickVerse()` 함수 하나로 모아 뒀습니다. 2번만 고치면 네 곳이 한꺼번에 바뀝니다.
> 3번을 빼먹으면 눌러도 말씀이 안 바뀌는 버튼이 남으니 함께 푸세요.

### 긴 영어 구절이 들어가도 괜찮나요

괜찮습니다. `fitVerse()` 가 본문 길이를 보고 **글자 크기를 30 → 21px 사이에서 자동으로 줄여**
목표 줄 수(6줄) 안에 맞춥니다. 카드 폭보다 긴 단어 하나가 들어와도 `breakLongWord()` 가
글자 단위로 쪼개 카드 밖으로 삐져나가지 않습니다.

## 개발

빌드 도구가 없습니다. 파일을 열어 고치고 저장하면 끝입니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

`file://`로 직접 열어도 대부분 동작하지만, 카메라(`getUserMedia`)와 블루투스는
보안 컨텍스트가 필요하므로 로컬 서버 또는 HTTPS로 여세요.

## 스택

단일 HTML + Vanilla JS · Web Bluetooth API (감열 프린터 직접 제어 — 안드로이드·데스크톱은 앱 불필요) ·
Canvas 2D (보정·디더링·카드 합성) · IndexedDB (기기 내 갤러리) · GitHub Pages

폰트: Nunito (제목·이름) + Lora (말씀·날짜) — 둘 다 Google Fonts

프린터 프로토콜: `0x51 0x78` 프레임 + CRC8 (방식 A), `0x22 0x21` 프레임 (방식 B, MXW01 계열),
384px 행 단위 비트맵(LSB 우선), 에너지/급지 제어
